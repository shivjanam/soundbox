How It Works

Three Steps to Live Payment Confirmation

From install to first broadcast in under an hour.

1

Install Free Software

Install our free Windows software on any PC in your store or back office. Windows 7, 10, 11 supported.

soundbridge-setup.exe /silent
2

Trigger a REST API Call

From your billing/ERP system, fire one lightweight POST with amount, transaction ID, and device ID.

POST /api/v1/dqr/generate { amount, txn_id, device_id, order_id }
3

Instant Broadcast

Payment confirmation is broadcast to the Soundbox speaker and Dynamic QR display in real time.

200 OK · < 50 ms · audio + display
